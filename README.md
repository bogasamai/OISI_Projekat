# Sajam Knjiga 2025

Projekat za faks. Radi upravljanje podacima o sajmu.

## Sta ima u programu:
- Unos i prikaz posetilaca, autora, knjiga i izdavaca.
- Provera da sef izdavaca ima bar 5 godina iskustva.
- Cuvanje svega u tekstualne fajlove unutar foldera /podaci.

## Kako se pali:
1. Otvoris u Visual Studiju.
2. Kliknes Run.
3. Kad zavrsis, obavezno izadji preko opcije 5 da se podaci sacuvaju.
